TR01.02 - Calculadora amb captura d'errors

Fes clic al botó i escriu una operació quan t'ho demani:

Encara no s'ha executat cap operació.

🧪 Proves suggerides (segons CodiError2.pdf):

  • 3+5 → 3 + 5 = 8
  • 3.5 * 2 → 3.5 * 2 = 7
  • -5 + 2 → -5 + 2 = -3
  • 10 % 3 → 10 % 3 = 1
  • 8 / 0 → Error: No es pot dividir entre zero
  • 8 % 0 → Error: No es pot calcular el mòdul entre zero
  • 1 + 2 + 3 → Error: Només es permet una operació
  • hola → Error: Només es permeten nombres i operadors
  • .5 + 1 → Error: Els decimals han de començar amb un dígit
  • (Cancel·lar) → Error: Has cancel·lat l'operació
